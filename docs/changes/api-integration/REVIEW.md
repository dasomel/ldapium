**제안하는 단계별 수용 기준**

1. **계약 고정:** 지원 릴리스의 경로·DTO·권한·오류·PUT 의미를 OpenAPI로 명시하고 문서 차이를 수정. 미지원 API는 JSON 404를 보장하며, 생성 SDK로 LDAP 쿠키 흐름과 SSO 차단 동작을 실제 검증.
2. **읽기 전용 서비스 연동:** 만료·폐기 가능한 서비스 인증과 명시적 read/subtree scope 도입. 10,000개 이상 cursor 조회의 누락·중복, 범위 밖 접근 거부, admin bind에서도 비밀 redaction을 실 LDAP로 검증.
3. **안전한 쓰기:** 대상 범위·작업별 권한, 조건부 수정, idempotency, 부분 성공 응답·복구 절차 확정. 응답 유실 후 재전송, Add 후 비밀번호 실패, 동시 수정·삭제를 재현해 검증.
4. **운영·에이전트 적용:** 필요한 장기 작업에 내구성 ID·상태·취소·재시작 복구·timeout·retry 계약 추가. 위험 작업은 계획/미리보기와 감사 상관관계를 검증. Schema/ACL/replication/restore HTTP 제어는 별도 설계 수용 후 노출.
